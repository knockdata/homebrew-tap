# knockdata/tap

Homebrew formula and cask for [ObjectExplorer](https://objectexplorer.com).

```sh
brew install knockdata/tap/objectexplorer             # the command line and server (macOS, Linux)
brew services start objectexplorer                    # as a service on http://127.0.0.1:9421
brew install --cask knockdata/tap/objectexplorer-app  # the desktop app (macOS)
```

Or tap once, then use the short names:

```sh
brew tap knockdata/tap
brew install objectexplorer
```

The files here are written by the release workflow of
[knockdata/objectexplorer](https://github.com/knockdata/objectexplorer) at each release.
